# rock-paper-scissors

The fourth porject in the Foundations course of The Odin Project.

It didn't take too long to build - I had a couple complications with it, but nothing too bad.

Contrary to the Rock-Paper-Scissors project, I didn't have that many extra ideas I wanted to add. I implemented a slider for the grid size (don't let Zach see how I stole his idea!), a color picker, a canvas clearing button, and also painting by click (and drag), instead of simply hovering - making it a bit more similar to my favourite code editor, MS Paint. I could have played around with opacity, but I didn't like it.

(I also somewhat optimized it by using a different method for handling the individual fields than described in the assignment, but honestly, it doesn't help a lot. Having 10k divs on a page will never be easy on the browser.)
